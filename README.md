# Estimasi Pendapatan Global Video Game di Wilayah Asia
Proyek ini bertujuan untuk melakukan analisis statistik dan estimasi pendapatan global video game di wilayah Asia dengan menerapkan metode **Regresi Linear Sederhana**.

## Deskripsi Proyek
Proyek ini menganalisis hubungan antara variabel-variabel dalam dataset video game untuk memprediksi pendapatan. Dengan menggunakan Python, kita membangun model statistik yang membantu memahami tren dan korelasi data penjualan.

## Struktur Repository
* `rea_games_dataset_updated.csv`: Dataset utama yang berisi data penjualan dan metrik video game terkait.
* `regresi_penjualan_game.py`: Skrip Python yang berisi kode untuk memproses data dan membangun model regresi linear.
* `hasil_regresi_game.png`: Visualisasi grafik hasil analisis regresi yang menunjukkan hubungan antara variabel independen dan dependen.

## Hasil
Visualisasi dari model regresi dapat dilihat pada file `hasil_regresi_game.png`. Grafik tersebut merepresentasikan garis tren dari data penjualan yang dianalisis.
